# 2026-11-12 界面现代化验证

## 范围和约束

用户先审查后确认了五步实施与新增界面文案。范围为共用按钮焦点、应用内提示、无线分区、展示层筛选与状态。额外建议、拖动分隔条、跨重启折叠记忆均未纳入。不新增 NuGet 依赖，不改后台、IPC、网络恢复、配置结构或公开类型名称。

源码共有八个主页面和设置页。全应用审查确认首页已有状态主卡与指标，扫描层已有 SSID 去重、最强信号选择及信号降序，无需重复实现。确认弹窗共用 FluentDialogWindow；托盘通知、系统文件夹选择器、异常兜底保留各自原有通道。

## 改动前后

| 项目 | 改动前 | 改动后 |
|---|---|---|
| 按钮焦点 | 默认焦点装饰与模板内外框可能叠加，测速另有模板 | 共用键盘焦点装饰；焦点不改变内容尺寸，测速使用同一模板 |
| 应用内提示 | 库语义色大底，成功 2 秒、其他 5 秒，撤销单独创建 | 中性卡片、语义图标、可关闭；成功/信息 4 秒、警告 6 秒、错误常驻 |
| 提示生命周期 | 应用层无统一队列、去重和暂停规则 | 同时最多三条、超出排队，精确合并；悬停/键盘/详情暂停；排队期间不计时 |
| 提示布局 | 右下覆盖页面 | 底部独立布局区，受窗口高度约束，不盖住顶部操作；多行原文可展开详情 |
| 无线列表 | 外层页面自然增高，优先级列表被长列表推走 | 上下可折叠分区、数量徽标、有限视口和行回收；各表独立滚动 |
| 展示层筛选 | 无搜索和过滤，信号为数字 | 搜索、仅未添加、名称/信号排序、无匹配时清除条件；源集合不变 |
| 连接展示 | 无连接中按钮反馈，列表无当前连接标记 | 进度内容在完成/异常后恢复；当前连接字重、背景与图标标记，选中框仍独立 |
| 小工作区 | 两表完全测量，依赖整页滚动 | 紧凑令牌、当前连接详情折叠、紧凑表头；低于常规最小高度时可折叠已读分区 |

列表的默认 40%/60% 权重用于分配空间；必要时优先保证标题、表头和至少一行的阅读空间，同时检查周围网络分区不超过页面可视高度 40%。不使用无限测量或单纯调大固定高度。

## 文件与风险

- `Themes/Buttons.xaml`、测速页及 `MainWindow.xaml`：共用按钮、提示承载区、无线列表模板。
- `Presentation/FeedbackPresenter.cs`、`FeedbackQueue.cs`：提示外观、队列、暂停与动画；确认窗口和托盘通知继续使用原有通道，不能将需用户决定的模态窗口替换成自动消失提示。
- `Presentation/WifiListView.cs`、`WifiRowPresentation.cs`、`ButtonActivityPresentation.cs`、`ResponsiveLayout.cs` 及 `MainWindow.WifiList.cs`：展示筛选、排序、图标和自适应阅读空间；现有网络互斥、恢复策略与配置格式不变。
- `MainWindow.CurrentWifi.cs`、`MainWindow.xaml.cs`：从现有连接快照更新行标记，接入筛选与活动内容，不增加网络查询。
- `Themes/Tokens.Common.xaml` 和三主题调色板：新增令牌；`Localizer.cs` 仅增加已授权界面文案。
- 回归测试覆盖四语义×三主题提示、队列计时、两个分区折叠与限高、虚拟化、无外层滚动、焦点环、过滤不改源、当前连接和按钮内容恢复。

主要风险是小窗口的阅读空间和系统合成差异。筛选栏放在分区标题内并随折叠收起；紧凑高度由令牌计算，包含展开按钮描边。恢复列表始终有标题入口，极小工作区可折叠已读分区阅读。状态读取失败时不展示过期的当前连接标记。

连接错误仍保留原错误原文：现有返回值没有可靠的“无可见接入点”类型，不能把所有失败都改写成路由器不在附近，因此本次没有套用该示例文案或增加可能误导的重扫动作。

额外建议仍待单独确认：降低危险按钮整块粉红的强调度、全应用遗留硬编码令牌收敛、徽标视觉统一、首页进一步精简、弹窗/托盘图标与标题栏一致性复核。未借本次任务实施这些额外改动。

## 设计令牌

| 类别 | 本次使用或补充 |
|---|---|
| 色彩 | `SurfaceCardBrush` 中性卡片；`StatusHealthy/Info/Warning/DangerBrush` 仅提示语义图标；高对比使用动态系统色 |
| 字号 | 提示标题 `FontBody=14`，正文 `FontFeedbackBody=13`；信号/进度图标 `ActivityIconSize=16` |
| 间距 | 4/8 栅格；提示卡片内边距 16、卡间距 8；紧凑筛选内边距 `WifiFilterPadding=8,0` |
| 圆角/描边 | 复用卡片 8、控件 4；普通描边 1、键盘焦点描边 2 和外间隙 3 |
| 阴影 | `FeedbackShadow`：深浅色轻阴影，高对比关闭阴影 |
| 布局 | 提示宽 360/最大 420；筛选宽度 128、排序最小宽 112；控件高度正常 36/紧凑 32 |
| 动效 | 提示入场 200ms、出场 150ms、位移 8；展开箭头 150ms；遵循系统关闭动画 |

这些值集中在主题资源中，不把尺寸和颜色散落到页面事件或业务代码。全应用既有硬编码的进一步清理属于额外建议。
