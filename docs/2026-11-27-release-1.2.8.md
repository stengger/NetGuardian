本版本交付 **Wi-Fi 网页认证（Captive Portal）自动登录闭环**：桌面端增加「设置自动认证」向导（支持门户入口发现、控件定位识别、固定下拉选项确认、账号密码/单按钮放行以及占位替换/受限直填两种提交策略，试登并经同网卡公网验证通过后才标记就绪）；凭据经 Windows DPAPI 加密保存（机器配置限 `SYSTEM` 与管理员读取）；后台通过继承匿名管道与 Job Object 托管无头 Edge，经目标 Wi-Fi 出口绑定与白名单转发执行认证，遇到密码错误或套餐到期自动暂停防锁号并回退切换备用 Wi-Fi。校园网实机弹页窗口与 `SYSTEM` 会话现场切网仍待在现场维护窗口完成最终实机验收。
