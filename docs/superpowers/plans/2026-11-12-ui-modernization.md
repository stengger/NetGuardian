# 界面现代化实施计划

目标：落实用户已确认的五步审查方案，以共用主题资源和展示层改动修复按钮焦点、提示及无线列表。

约束：不新增依赖，不修改后台、IPC、网络恢复、配置格式或公开类型名称。新增中文文案限已确认项目。额外建议、拖动分隔条、跨重启记忆不实施。

在当前会话顺序执行；每步先用回归测试证实缺陷，再实现、运行 `dotnet build NetGuardian.sln` 和 `dotnet test NetGuardian.sln`，检查 diff 后仅提交相关文件。

- [x] 1. 按钮：`Themes/Buttons.xaml` 统一键盘焦点装饰，测速页复用共用模板；测试焦点不改变尺寸、禁用状态及三主题。
- [x] 2. 提示外观：新增共用提示视图、主题令牌和展示入口，替换普通反馈及撤销提示，保留确认框与托盘通道；测试四种语义、长文与关闭动作。
- [x] 3. 提示行为：展示层队列限制三条、精确合并、悬停和焦点暂停、语义计时、减少动画、详情及专用区域；测试生命周期、撤销隔离与布局。
- [x] 4. 无线布局：有限视口的上下 Expander 分区、默认 40% 上限、独立滚动和虚拟化；更新旧布局契约，测试 32/100 条、折叠、详情、最小窗口。
- [x] 5. 无线展示：集合视图搜索、未添加过滤、信号/名称排序；增加信号图标、当前连接标记和连接进度展示，保留网络操作流程；测试过滤不改源集合及当前状态刷新。
- [x] 6. 汇总：保存同尺寸前后截图、验证记录和手动清单；发布已验证提交，备份并校验本机必要组件，界面运行时请用户手动从托盘退出后再替换。

手动验收：32+ 网络、深浅色、高对比、100/125/150% DPI、最小窗口、键盘/鼠标焦点、真实连接结果与减少动画。桌面夹具不启动网络操作。
