# 审查问题修复计划

目标：修复本轮审查确认的整机重启授权、SSID 比较、公网 IP 手动刷新问题。

约束：沿用 .NET 8、xUnit 和现有模块，不增加依赖；保留用户现有文档修改；不执行真实切网、重启或安装。用户已授权开始修复，由当前会话直接执行。

## 任务一：重启前核对当前策略

- 在 `RecoveryBudgetTests.cs` 覆盖已完成两种动作后关闭主开关或任一细分动作的场景，以及旧配置兼容和允许重启场景。
- `ComputerRestartPlanner` 增加接受完整 `AppSettings` 的判定入口，统一检查当前授权；Guardian 使用该入口，并在设备复核后再次判定。
- 先观察测试失败，再运行恢复相关测试和 Guardian 构建；通过后提交“修复整机重启未核对当前高风险策略的问题”。

## 任务二：SSID 使用精确身份

- 覆盖大小写及首尾空格不同的 SSID 候选、关联校验和独立冷却。
- `RecoveryPlanner`、`MonitoringEngine` 统一使用原始字符串及 Ordinal 比较；检查界面相同调用链，避免添加或选择网络时仍混淆名称。
- 先观察回归失败，再运行恢复及无线相关测试；通过后提交“修复无线网络名称比较与冷却记录混淆的问题”。

## 任务三：手动刷新绕过公网 IP 缓存

- 在 `PublicIpInfoTests.cs` 覆盖默认缓存、强制刷新后地址更新及取消行为。
- `PublicIpInfoService.GetAsync` 保留默认缓存并增加强制刷新参数；界面手动查询明确传入强制刷新。
- 先观察测试失败，再运行核心完整测试、桌面完整测试和解决方案构建；通过后提交“修复公网 IP 手动刷新返回旧缓存的问题”。
