# Windows 安装包实施计划

用户已要求提供双击安装、开始菜单启动及系统设置卸载方式。本轮直接实现该明确范围，不发布 GitHub Release、不操作现有正式安装。

## 设计与边界

采用 Inno Setup 7 编译安装器；相比另写安装引擎，直接使用其目录选择、快捷方式及卸载登记机制。发布 Windows x64 自包含程序，随包携带 .NET 8 运行时。普通 ZIP 仍可由相同发布目录生成。

安装器默认只安装文件，不启用后台或高风险恢复。升级要求退出界面并先停止后台；卸载经明确确认后调用既有安全停止脚本，失败即拒绝删除。配置及日志位于用户/机器数据目录，不随卸载删除。复用现有后台脚本，并让选择的安装目录与后台注册目录一致。

## 执行步骤

1. 补充独立 PowerShell 回归：正在运行的程序阻止安装、后台指向其他目录时拒绝接管、卸载失败不得继续、发布目录附带所需入口和脚本。先观察失败。
2. 增加安装维护辅助脚本和 Inno Setup 源文件，使用稳定 AppId；开始菜单入口和可选桌面快捷方式指向真实程序。
3. 发布脚本支持指定运行时及自包含模式，始终先还原和完整测试；发布目录只打包所需程序和支持文件。增加安装包构建脚本，接受明确版本和编译器路径，输出 Setup.exe 及 SHA-256。
4. 编译真实安装包，执行脚本回归、完整 xUnit、构建及差异检查。使用隔离目录/测试替身核对安装与卸载逻辑，不对本机正式版本做试装。
5. README 记录用户安装方式、运行时区别、构建依赖和 Release 附件。验证通过后分逻辑单元中文提交；产物留在 dist，不提交 Git。

## 重点验证

- 卸载过程中后台停止失败，必须在删除文件前中止。
- 安装目录含空格和中文时，命令参数及包内入口仍有效。
- 已有机器配置保持原样，不自动注册/启动后台。
- Windows PowerShell 5.1 能正确读取发布脚本的中文；包中支持脚本使用 UTF-8 BOM。
- 包中同时包含管理界面、Guardian、所需运行时和后台维护脚本。
