# NetGuardian 界面优化实施计划

用户已确认对话中的问题清单、设计令牌、八页方案及延迟展示阈值。沿用 .NET 8 WPF、WPF-UI 4.3.0、XAML 动态资源和现有展示代码。

## 约束与工作方式

- 只调整样式、布局、组件结构、展示映射和交互反馈；不修改业务逻辑、数据结构、IPC 或后台接口。
- 保留现有中文原文；仅新增已确认的分组、图例、复制、筛选重置和禁用说明。沿用现有本地化机制。
- 不引入依赖、不重命名文件、不实施历史趋势或列宽持久化等额外建议。
- 当前工作区干净，在 `codex/fluent-ui-polish` 分支逐步实施；完整验证后按逻辑单元提交。
- 每步运行 `scripts/build.ps1`、Release 完整测试、`python scripts/check-contrast.py`、`git diff --check`，保留完整日志和退出码。新增展示判断先通过失败用例证明，再实现。

## 顺序与改动边界

1. 设计基础：修改 `Themes/Tokens.Common.xaml`、三套调色板及 `MainWindow.xaml` 公共样式；统一语义色、按钮层级、字号、间距和焦点，不改变按钮可用判定。
2. 表格与小窗口：修改主窗口表格模板及 `Presentation` 展示辅助；保留完整数据，增加复制入口，窄窗口将次要字段移入可展开详情。验证长 SSID、IPv6、完整行与焦点可达。
3. 首页：修改主窗口首页及其展示方法；增加状态图标、探针指标、独立七天统计及事件时间线。复用现有报告和汇总，零次恢复尝试显示破折号，不制造历史趋势。
4. Wi-Fi 和侧栏：修改当前连接呈现、工具栏、列表拖拽反馈、流量图例；保留已有扫描、连接、排序及短窗口完整行契约。
5. 网络质量与诊断：修改质量页、工具标签的布局和空状态；沿用会话状态、真实取消与不定进度，不伪造进度百分比。
6. DNS 与适配器：修改对应模板和展示辅助；现有连接状态徽标化、地址分行、未连接弱化，保留错误、完整地址及原有操作边界。
7. 恢复策略：修改页面布局；按检测、恢复动作、探测目标分组，高风险项包裹警示卡，保留原有默认拒绝二次确认与保存流程。
8. 事件日志：修改日志模板和空状态交互；保留关键词、级别、来源筛选及跟随最新、详情功能，新增重置筛选入口。

## 验证与交付

- 桌面布局使用现有 `DesktopFixture` 加载真实产品 XAML，不启动监控或执行切网；按同一数据和窗口保存前后位图。
- 覆盖 1180×760、1040×660、960×500，小窗口完整数据行、操作按钮、长文本、键盘复制、焦点、深浅色和高对比资源；实机缩放检查与离屏布局检查分别记录。
- 每步提交前检查 `git status` 与 `git diff`，只暂存本步文件，记录中文提交信息、哈希、测试数和剩余改动。
- 最终从已验证提交隔离发布，核实 `C:\Program Files\NetGuardian` 与项目 `dist\NetGuardian`，备份必要组件并保留配置。界面仍运行时请用户从托盘退出；仅更新必要界面组件，不重启无关后台。
- 安装后核对哈希/构建标识与实际进程路径，交付前后对比、手动测试清单及未验证事项。
