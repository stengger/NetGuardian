## 主要优化内容

1. **「IP 信息」页表格融合展示**（`MainWindow.xaml` / `MainWindow.Diagnostics.cs` / `ProxyVpnPresentation.cs` / `Localizer.cs`）
   - 移除「网络诊断 → IP 信息」顶部独立的 `IpProxyVpnBanner` 横幅。
   - 新增「系统代理」与「活动 VPN / TUN」标准明细行，直接融合进下方 `IpInfoGrid` 表格中，与公网 IP、IPv6 双栈可达性、本地默认出口网卡保持统一表格式阅读体验。
2. **代理 / VPN 与默认出口自动实时刷新**（`MainWindow.Operations.cs` / `MainWindow.xaml.cs` / `MainWindow.Dashboard.cs`）
   - 切换进入「网络配置 → 接口概览」或「网络诊断 → IP 信息」时自动刷新一次。
   - 在上述任一页面可见时，每 **5 秒**自动静默刷新一次本地代理、VPN/TUN 与 IPv4 默认出口（以及选中接口详情或 IP 详情表对应行）。
   - 收到 Windows `NetworkChange.NetworkAddressChanged` 地址变更事件时立即刷新，开关 VPN/TUN 虚拟网卡后无需手动点击刷新按钮。
