## 主要新增功能

1. **无人值守与远程运维能力**
   - **远程告警通知（`NotificationSettings` / `AlertNotificationService` / `NotificationSettingsDialog`）**：支持通用 Webhook、企业微信、飞书、钉钉通知，内置测试发送与令牌脱敏，断网时自动入队缓存至多 20 条告警（`alerts/pending-notifications.json`）并在恢复联网后补发。
   - **每日维护窗口与临时暂停恢复（`MonitorPolicy` / `MonitoringEngine`）**：支持每日定时维护时段（支持跨夜如 `23:00–05:00`）及一键暂停自动恢复 1 小时，暂停期间仅维持检测与日志，不打断当前网络连接。
   - **主 Wi-Fi 低频回切与有线共存保护（`MonitoringEngine.Failback.cs` / `RecoveryPlanner`）**：处于备用 Wi-Fi 时按低频间隔先扫描可见性再回切主 Wi-Fi，公网验证失败自动回滚备用网；检测到有线网卡互联网可达时抑制高风险无线设备重启。
   - **一键导出脱敏诊断包（`DiagnosticBundleExporter`）**：输出 `.zip` 诊断包（含近 7 天日志/事件/质量基线、脱敏配置与代理/VPN 快照、运行状态），严格过滤 `portal-credentials/` 目录及敏感密钥。
2. **可观测性与全面只读网络信息检查**
   - **VPN 与系统代理检查器（`ProxyAndVpnInspector`）**：读取 Windows Internet Settings 注册表与环境代理变量（凭据脱敏）、500ms 本机端口探测以及活动 VPN/TUN 虚拟网卡识别，并在「网络配置 → 接口概览」与「网络诊断 → IP 信息」实时展示。
   - **7 天 / 30 天 SLA 与质量基线趋势图（`NetworkObservabilityAnalyzer` / `QualityBaselineStore` / `IncidentTimelineView`）**：节流记录 `quality-baseline-yyyyMM.jsonl`，计算 7 天 / 30 天可用率、MTTR、最长中断、恢复成功率、Wi-Fi 稳定性排行及 P50/P95 HTTPS 延迟趋势折线图。
   - **物理射频 / 默认路由 / 网卡扩展详情 / IPv6 双栈 / `hosts` 检查（`NetshWifiClient` / `NetworkEnvironmentInspector`）**：补充当前 Wi-Fi 频段、信道、制式、协商速率与 AP BSSID；选中网卡详情展示默认出口、IPv4 跃点数、MAC、链路速率、MTU、全局 IPv6 与 DHCP 状态；IP 信息展示本机/公网 IPv6 双栈可达状态；综合诊断报告检查 `hosts` 自定义映射及代理/VPN。
