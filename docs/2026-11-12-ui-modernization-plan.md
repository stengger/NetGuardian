# NetGuardian 界面整改执行计划

依据：[审查报告](2026-11-12-ui-audit.md)。用户已回复“继续”，接受报告中的推荐取舍。

## 约束

仅修改展示、样式、布局、可访问性和相应测试；不改中文文案、业务、后台、IPC、配置或依赖。所有新增外观值进入设计令牌。保留全部功能入口。

## 执行批次

- [x] 主题资源：补齐高对比标签头、按钮边界，库控件与主按钮使用同一蓝色角色令牌。文件：Palette.*、Buttons、HighContrastThemeTests。
- [x] 共用组件：提示区优先保障正文空间；按钮状态使用独立表面层，危险入口与最终确认分级；更新说明接入共用展开模板。文件：Buttons、Tokens、布局转换器、MainWindow、相关布局测试。
- [x] 页面密度：Wi-Fi 根据实际内容视口紧凑展示，保留可展开详情和全文提示；策略、设置、测速复用共用分组表面与间距，迁移重复卡片样式。文件：共用字典、ResponsiveLayout、MainWindow、SpeedTestView、布局测试。
- [x] 细节：单位字段绑定已有标签，错误播报语义一致；文本装饰图标复用 Fluent 符号；补展示代码令牌，复核托盘 Esc 的路由边界。
- [x] 收尾：完整构建和测试，重新生成三主题、三尺寸、三数据档、三输出密度矩阵，检查联系表与重点原图；记录真实系统 DPI 与读屏器等未覆盖项。
- [ ] 本机更新：先生成可复核发布文件并校验；核实运行路径，请用户手动托盘退出；备份并仅更新界面组件，同时检查项目启动目录；启动后核验路径和哈希。

每批先补关键约束测试确认旧实现失败，再做最小修改；执行 dotnet build/test，生成对应截图。提交前检查 git status/diff，仅提交相关源码、测试与文档；不提交生成物和真实网络数据。基线托盘 Esc 失败不作为其他测试全通过的理由，原断言保留，根因未证实前不改产品掩盖问题。

正式验证与已知覆盖边界见 [整改结果](2026-11-12-ui-modernization-result.md)。本机更新包与管理员只读预检已完成；仅等待用户手动托盘退出后执行安装和启动核验。
