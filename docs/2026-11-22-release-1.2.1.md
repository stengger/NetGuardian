# NetGuardian v1.2.1

本次正式版交付 v1.2.0 之后已经实现的界面、检测指标和故障记录改进，不代表 v2.0 首发功能已经全部完成。

## 本次改进

- 恢复五栏导航，直接进入概览、网络配置、自动恢复、网络诊断和故障记录；设置保留独立入口。
- 网关和 DNS 指标按所属网络保留最近一次实际测量，轻量检测跳过项目时不再直接清空读数。详情保留检测时间和实际探针结果。
- 将一次失联、恢复动作和公网复测串联为故障记录。旧日志按已有证据展示，区分未记录、切换尝试与已验证恢复，不补造结果。
- 加强故障列表与详情的分区，选中项采用圆角淡色描边，并保留键盘焦点反馈。
- 在首次显示前隐藏桌面测试窗口，避免测试窗口在 Windows 任务视图中闪现。
- 提供受信双源更新客户端和离线签名清单生成工具；正式备用域名与公钥尚未配置，本版仍通过 GitHub 更新，并明确显示备用源尚未启用。

## 已知限制

- 国内无代理网络下的备用源发现、下载、安装和重启尚未完成公开现场验收。
- 另一台 v1.1.6 电脑的“等待界面退出超时”已定位到网络操作收尾等待，具体系统状态仍需 Windows 无线事件核实。本版不宣称修复该问题，重复下载不能绕过旧进程的退出等待。
- 工作服务监测和无人值守前自检不在本次发行范围内。

## 升级

已经安装在 Program Files 下的版本可从“设置 → 软件更新”检查、下载并安装本版。安装包仍使用 SHA-256 整包校验。

旧版如等待退出超时，应先正常退出并停止开机后台守护，再运行正式 Setup 覆盖安装到原目录。配置和日志保留；后台无法安全停止时不要强制覆盖安装。
